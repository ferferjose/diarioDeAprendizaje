Control de versiones

GIT: es un SERVICIO (estándar) de comunicación y gestión de información entre local y remoto.

Áreas

  • Directorio de trabajo
  • Staging
  • Repositorio Local
  • Repositorio Remoto

Estado de los ficheros

  • Untracked
  • Unmodified
  • Modified
  • Staged
  • Comitted

Trabajar con ramas

  • Bifurcaciones de nuevas versiones, con respecto a la rama máster.
  • Todos los commit se aplican sobre una rama.
  • Por defecto trabajamos sobre la rama máster.
  • Crear una rama consiste en copiar un commit de una rama determinada, pásalo a la nueva rama y continuar el trabajo, sin afectar el flujo del trabajo principal.

Comandos Principales

  • git init 🡢 Inicia el proyecto
  • git add . 🡢 Añade los archivos al proyecto
  • git branch –m [old_nombre_rama] [new_nombre_rama] 🡢 cambia el nombre de una rama
  • git remote add origin [url] 🡢 Crea el repositorio remoto
  • git commit -m "Mensaje" 🡢 Hace el commit con un mensaje
  • git push -u origin main 🡢 Sube al repositorio todo
  • git clone [remote_repo] [directory_local] 🡢 se usa para copiar un repositorio remoto en local.
  • git pull [servidor_remoto] 🡢 fusiona todos los cambios que se han hecho en el repositorio remoto con el directorio de trabajo local.
  • git fetch [nombre_servidor_remoto] 🡢 recupera todos los datos del proyecto remoto que no tengas todavía en el repositorio local.
  • git merge [nombre rama] 🡢 se usa para fusionar una rama con otra rama activa.

Otros Comandos

  • git show 🡢 te permite ver el último commit a qué ramas se encuentra pegado.
  • git reset HEAD [nombre_archivo] 🡢 Untrackea los archivos nombrados
  • git log --oneline --all 🡢 Nos enseña los commits hechos de todas las ramas
  • git clean -n 🡢 Te dice que archivos se van a borrar (solo untrackeds)
  • git clean -f 🡢 Borra los archivos untracked
  • git checkout [id_commit] 🡢 Te lleva a ese commit
  • git checkout [branch] 🡢 Te lleva a esa rama
  • git reset --soft HEAD^ 🡢 Te lleva al commit anterior borrando el actual y poniendo los archivos en added
  • git reset --mixed HEAD^ 🡢 Te lleva al commit anterior borrando el actual y poniendo los archivos en untracked
  • git reset --hard HEAD^ 🡢 Te lleva al commit anterior borrando el actual y borra los archivos
  • git revert [id_commit] 🡢 Revierte un commit específico creando un nuevo commit que deshace los cambios del commit mencionado.
  • git tag -a [nombre] -m "Descripción o mensaje" 🡢 Crea una etiqueta anotada con un nombre y un mensaje descriptivo, útil para marcar versiones.
  • git tag -a [nombre] [id_commit] -m "Mensaje" 🡢 Asigna una etiqueta anotada a un commit específico con un mensaje que describe la etiqueta.
  • git push origin [nombre_tag] 🡢 Sube una etiqueta (tag) específica al repositorio remoto para compartirla con otros usuarios.
  • git commit --amend -m "Texto" 🡢 Permite modificar el mensaje del último commit, ideal para corregir errores en el mensaje.
  • git revert [nombre_rama]~[numero_commit] [nombre_rama]~[numero_commit] 🡢 Revierte uno o más commits en una rama especificando la posición de los commits que quieres deshacer.
  • git tag -a [nombre] -m "Descripción o mensaje" 🡢 Crea una nueva etiqueta anotada con un nombre y mensaje, útil para marcar versiones o puntos importantes.
  • git pull [servidor_remoto] [rama] 🡢 se baja una rama del servidor remoto
  • git diff 🡢 se usa para ver una lista de todos los conflictos presentes
  • git diff [branch_origen] [branch_destino] 🡢 ver los conflictos que hay entre ramas, por ejemplo antes de fusionarlas.
  • git merge --abort 🡢 descarta la fusión por conflictos en la misma.
