Apache

Apache, o Apache HTTP Server, es un servidor web de código abierto ampliamente utilizado para alojar sitios web y aplicaciones. Permite servir contenido estático y dinámico a través de internet, es altamente configurable y compatible con múltiples sistemas operativos, como Linux y Windows. Es parte fundamental de la pila LAMP (Linux, Apache, MySQL, PHP).
